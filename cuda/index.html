CUDA Learning Notes

A beginner-friendly walk from "what is a thread?" to "how do I pick launch dimensions on any GPU?"

Reading Order

Each chapter builds on the previous one. Start at the top and work down — by the end you'll have the mental model and a practical process for designing kernels.

  1. Foundations Primer — A Beginner's Mental Model What a thread, block, and grid actually are. Who can see which memory. How threads cooperate without touching each other. Warps and "zero-overhead scheduling." The myths every beginner holds.
  2. Grid-Stride Loops — Handling Data Bigger Than Your Threads The canonical pattern for processing arrays of any size with a fixed launch grid. Why you shouldn't launch one thread per element. Correctness first, then performance.
  3. Tiled Shared Memory — Stop Hammering Global Memory The technique that cuts global-memory traffic by a factor of TILE. Cooperative loads, the two-barrier dance, boundary handling, and the arithmetic of why it works.
  4. Worked Example — Tiled + Strided Matmul on GT200 A hand-traced 5×4 × 4×7 matrix multiply on a real (vintage) GPU, with every edge case: partial tiles, zero padding, grid-stride wrap-around. The numbers you can verify with pencil and paper.
  5. Interactive Animation — Watch It Run An HTML+SVG animation of the combined pattern with sliders for M, K, N, TILE, grid size, and speed. Click any output tile, step through phases, see the barrier synchronize threads in real time.
  6. Launch Design Process — Picking Grid, Block, and Tile from Hardware A repeatable procedure for choosing dimensions from first principles. Four limits compete, the tightest wins. Includes a live calculator with 8 GPU presets from Tesla (2008) to Hopper (2022).
